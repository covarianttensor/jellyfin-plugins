# Jellyfin Plugin Repository

A custom plugin repository for Jellyfin Media Server.

## How to Add This Repository to Jellyfin

1. Open your Jellyfin Web Interface with an administrator account.
2. Go to **Dashboard** &rarr; **Plugins** &rarr; **Repositories**.
3. Click the **+** (Add) button.
4. Enter the repository details:
   - **Repository Name:** `CovariantTensor Plugins`
   - **Repository URL:**
     ```text
     https://raw.githubusercontent.com/covarianttensor/jellyfin-plugins/main/manifest.json
     ```
5. Click **Save**.
6. Switch to the **Catalog** tab inside Plugins.
7. Select the desired plugin, choose the latest version, and click **Install**.
8. Restart your Jellyfin server when prompted to activate the plugin.
